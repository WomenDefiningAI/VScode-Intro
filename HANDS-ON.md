# Hands On 🌟

Welcome to your first hands-on Git workflow! This is a practice file where you'll make your first change, commit it, and push it to GitHub. It's about seeing your changes get saved locally and on Github.

## Step 1: Make Your First Edit

Let's start with a real, visual change before we get into the Git workflow.

1. In the Explorer panel on the left, find and click **`sample.html`**
2. Take a look at the structure: HTML tags, a `<style>` block for colors and spacing, and a button
3. Find the line `<h1>Hello, Build TogetHER!</h1>` and change the text between the tags to something of your own — like `<h1>Hello, [Your Name]!</h1>`
4. Inside the `<style>` block, find `color: #6a1b9a;` and change the hex code to a different color (try `#1b7a4a` for green or `#c0392b` for red)
5. Save the file with **Ctrl+S** (Windows/Linux) or **Cmd+S** (Mac)
6. See your change rendered: right-click **`sample.html`** in the Explorer and choose **Reveal in File Explorer** (Windows) or **Reveal in Finder** (Mac), then double-click the file to open it in your browser

That's your first file change. Now let's check it off and send it to GitHub.

## Demo: Which AI Coding Experience Feels Best to You?

Let's ask three AI coding tools to complete the same small task. This is not a contest to find one universal winner. Pay attention to where you type, how the tool shows its work, what it asks you to approve, and which experience feels most natural to you.

Use the same prompt each time, changing only the filename:

> Create a beginner-friendly JavaScript file named `[filename]` with around 20 lines of code. Make a list of three workshop goals, print each goal with a checkbox, and finish with an encouraging message. Include a few short comments. Create the file, but do not run it or change any other files.

### Option 1: Chat in VS Code

1. Open **Chat** in the left sidebar of VS Code and select **Agent** mode in the chat box near the "+" so it can create a file.
2. Replace `[filename]` with `demo-chat.js` and submit the prompt.
3. Review any requested file-edit or tool approval before accepting it.
4. You should see a new file created in the Explorer view. Open the new file in the Explorer and review the result.

### Option 2: Claude Code in the Terminal (requires a Claude login)

1. Open VS Code's integrated terminal and enter `claude`.
2. Replace `[filename]` with `demo-claude-terminal.js` and submit the prompt.
3. Review Claude's proposed action and approve it when you are comfortable.
4. Open the new file in the Explorer and review the result.

### Option 3: Claude Code in the Sidebar

1. Select the Claude Code icon in the Activity Bar to open its sidebar.
2. Replace `[filename]` with `demo-claude-sidebar.js` and submit the prompt.
3. Review and approve the proposed file creation if prompted.
4. Open the new file in the Explorer and review the result.
