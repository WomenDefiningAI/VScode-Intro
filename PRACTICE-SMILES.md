# Practice Smiles 🌟

Welcome to your first hands-on Git workflow! This is a practice file where you'll make your first change, commit it, and push it to GitHub. It's not about writing code—it's about seeing your changes come to life.

## Build Together Accomplishments

Check off what you've done during this workshop:

- [ ] Cloned a repository to my computer
- [ ] Opened a repository in VS Code
- [ ] Made my first file change
- [ ] Committed my changes with a message
- [ ] Pushed my changes to GitHub
- [ ] Saw my changes live on GitHub.com

---

## How to Use This File

1. Check off the boxes as you complete each step during the workshop
2. When you're done, save the file (Ctrl+S or Cmd+S)
3. Go through the Git workflow: stage, commit, push
4. Then visit your repo on GitHub.com to see your changes there!

You just participated in the same workflow that professional developers use every day. Nice work! 🚀
